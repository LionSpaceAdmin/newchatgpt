# LIONS OF ZION — Baked Point-Cloud Intro

Standalone, zero-image-runtime cinematic intro.

Runtime network assets:
- `data/lion.pcbin.gz`: baked lion particles.
- `app.js`, `boot.js`, `styles.css`, `index.html`.

The development source lion is not deployed.
No `<img>`, image texture, `CanvasTexture`, or runtime lion bitmap is used.

Controls: Skip Intro, Escape = final frame, Space = pause/resume, Right Arrow = next segment, click/tap = anatomical explode/reassemble.
